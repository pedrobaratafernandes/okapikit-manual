# Palette

[:material-code-tags: Ver Código Fonte C#](https://github.com/VideojogosLusofona/OkapiKit/blob/main/Assets/OkapiKit/Scripts/Variables/Palette.cs){ .md-button }



Asset que define conjuntos de cores consistentes para o projeto.

## Configurações do Inspector

A Paleta é composta por uma lista de **Colors**:

- **Name**: Nome identificador (ex: "Dano", "Cura").
- **Color**: O valor da cor (RGBA).

## Funcionalidades do Editor

No Inspector da Paleta, podes usar botões para organizar:
- **Sort by Hue/Brightness/Saturation**: Ordena as cores automaticamente.
- **Export Texture**: Cria um PNG com as cores para uso externo.

## Como Criar

1. No Project, clique com o botão direito.
2. Selecione `Create` -> `Okapi Kit` -> `Palette`.
3. Adicione cores clicando no botão `+`.
