Altera definições globais do sistema.

![Action Change System Option](../../assets/images/action/Action-Change-System-Option.png)

## Configurações do Inspector

| Campo | Função | Detalhes |
| :--- | :--- | :--- |
| **Active** | Ativação | Define se o componente está ligado e pronto para funcionar. |
| **Tags** | Etiquetas | Etiquetas inteligentes (Hypertags) usadas para identificação e filtros. |
| **Conditions** | Condições | Lista de requisitos (ex: variáveis ou tokens) que têm de ser verdadeiros para a execução. |
| **Change Type** | Opção. | Atualmente focado na **Visibilidade do Cursor** do rato. |
| **State** | Estado. | **Enable** (Mostra o cursor), **Disable** (Esconde) ou **Toggle**. |

## Como configurar

1. **Use**: para esconder o rato durante o jogo e mostrá-lo novamente quando o menu de pausa for aberto.

2. **Esta**: alteração é global e afeta todo o jogo.
